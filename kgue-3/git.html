1Projekt auf GitLab anlegen

Im Browser auf git.rwth-aachen.de anmelden und ein neues, leeres Projekt anlegen. GitLab zeigt dir danach seine Adresse.

2Repository clonen

$ git clone git@git.rwth-aachen.de:NAME/PROJEKT.git $ cd PROJEKT

Leere Projekte melden eine Warnung. Die ist harmlos.

3Ein Rust-Programm darin anlegen

$ cargo init $ cargo run

cargo init macht den Ordner zu einem Rust-Projekt.

4Hochladen

$ git add . $ git commit -m "Erstes Rust-Programm" $ git push

Git ist Pflicht.

Git ist ein Grundwerkzeug. Jede Ingenieurin und jeder Ingenieur muss damit arbeiten können, genauso mit GitLab oder GitHub.

Das ist kein Extra, sondern das absolute Minimum in jedem Team und in jedem Job.

Mein Tipp: Nimm Git ab heute für jede Übung und jedes eigene Projekt.

Für zu Hause

nicht klausurrelevant, aber im echten Leben Pflicht
Branches anlegen und wechseln: git branch, git switch
Branches zusammenführen und Konflikte lösen: git merge
Merge Requests (GitLab) und Pull Requests (GitHub)
Änderungen ansehen und zurücknehmen: git diff, git restore, git revert
Dateien ausschließen: .gitignore
SSH-Schlüssel für GitLab und GitHub einrichten
